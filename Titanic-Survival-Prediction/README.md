# 🚢 Titanic Survival Prediction

A beginner-friendly **Machine Learning classification project** that predicts whether a passenger on the Titanic survived or not.

The project uses passenger information such as **age, gender, passenger class, fare, family size, and other available features** to train and compare machine learning models for survival prediction.

## 📌 Project Overview

The sinking of the Titanic is one of the most well-known historical disasters and is also a popular dataset for learning machine learning.

In this project, the Titanic dataset is cleaned, explored, and used to build classification models that predict the target variable:

* **1 → Survived**
* **0 → Did Not Survive**

The project also compares different machine learning models to identify which model performs best on the dataset.

## 🎯 Objectives

* Clean and preprocess the Titanic dataset.
* Perform exploratory data analysis (EDA).
* Analyze the factors affecting passenger survival.
* Prepare features for machine learning.
* Train multiple classification models.
* Compare model performance.
* Generate survival predictions.
* Identify the best-performing model.

## 📊 Dataset

The dataset contains information about Titanic passengers.

Typical features include:

* `PassengerId` – Unique passenger identifier
* `Survived` – Survival status / target variable
* `Pclass` – Passenger class
* `Name` – Passenger name
* `Sex` – Passenger gender
* `Age` – Passenger age
* `SibSp` – Number of siblings/spouses aboard
* `Parch` – Number of parents/children aboard
* `Ticket` – Ticket number
* `Fare` – Ticket fare
* `Cabin` – Cabin information
* `Embarked` – Port of embarkation
